# 05 Finalidad secundaria

## Objetivo

Responder el caso de usar datos para promociones.

## Procedimiento

Compare ese uso con atencion al cliente y facturacion.

## Resultado

1. Tener los datos no significa poder usarlos para todo.

2. Preguntaria para que se pidieron, que se informo al cliente, si se permite ese otro uso y si necesita dar su consentimiento. Tambien quien los recibira, cuanto tiempo y como puede pedir que no se usen para promociones.

3. Solo daria los datos que necesite la promocion autorizada: tal vez grupo de edad, ciudad, compras que se usen y un contacto. No toda la ficha ni el RFC. La tabla clientes no trae las compras.

4. Marketing no necesita entrar a toda la tabla. Se le puede preparar lo que si se le permita usar.

5. Usaria una vista con menos campos y permisos limitados. El envio debe revisar quien no debe recibir promociones, tambien en las copias.

## Analisis

Atender una duda y mandar publicidad son cosas distintas. Antes lo deben revisar el area que pide los datos, privacidad y juridico.

## Conclusion

Primero se revisa si se pueden usar y despues se prepara la lista, no al reves.
