# POL-05 - Uso de datos sensibles

Objetivo: Limitar la exposicion de datos personales

Alcance: RFC, contacto, auditorias y registros que los contengan

Regla: Dar acceso solo cuando se apruebe para que se necesita y revisar permisos cada mes. Guardar las operaciones que permita el sistema y anotar lo que no se registra

Responsable: Propietario aprueba; DBA aplica; auditoria revisa

Excepciones: Acceso urgente con autorizacion y registro posterior

Evidencia: E2-privilegios.txt y E4-muestra-auditoria.txt; no hay registro completo de lecturas

Revision: cada año y cuando cambie el proceso
