# POL-01 - Acceso

Objetivo: Evitar accesos innecesarios

Alcance: Clientes, auditoria y bitacoras de ambos motores

Regla: Cada acceso se solicita explicando para que se necesita. El propietario lo aprueba, el DBA lo aplica y seguridad revisa los permisos cada mes

Responsable: Propietario decide; DBA ejecuta

Excepciones: Acceso urgente con aprobacion registrada del responsable

Evidencia: E2-privilegios.txt muestra permisos actuales; las solicitudes y revision mensual no existen todavia

Revision: cada año y cuando cambie el proceso
